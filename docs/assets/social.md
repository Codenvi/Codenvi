⚡ Codenvi 1.0.40 is out.
👏 Open-source command center for Claude Code - manage multiple projects, with multiple sessions on multiple PCs at once, all from a single page on the Android app.

What's new:
🔹 Multimode - send one prompt to several projects from one screen, with unseen-reply markers
🔹 Commit, Publish and Pull from the chat header
🔹 Start a project script (like a dev server) from your phone, with live output on the PC
🔹 Pair with a QR code

End-to-end encrypted, on a server you own.
🔷 https://codenvi.github.io/Codenvi/
