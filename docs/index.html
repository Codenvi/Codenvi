Features

Your coding agent, in your pocket

Everything runs on machines you control. The phone is the remote.

End-to-end encrypted

Prompts, replies, project names and commit messages are encrypted with AES-256-GCM using a key only your PC and phone hold. The server relays ciphertext.

Your server, no accounts

You host the relay on your own VPS and choose one password. Each app then holds its own credential, so you can revoke one without touching the others.

Many PCs, no open ports

Register project folders on every Windows PC. Both apps only connect outbound, so nothing is exposed and there is no port forwarding.

Safe by default

Results are committed to a dev branch. Codenvi never pushes, never merges to main and never rewrites history. Roll back to any commit from the phone.

Voice in, voice out

Dictate a prompt, review it, then send. Have any reply read aloud. Multimode sends to any project on any connected PC from one screen.

Pair with a QR code

Press Connect a phone on the PC and scan the code. The phone links to the server and receives that PC's key in one step.

How it works

Three steps from zero to first prompt

Set it up once. After that, every PC and phone is one tap away.

  1. Deploy your server

    Fork the repository, add four GitHub secrets and push with [server] in the commit message. The deploy sets up nginx, HTTPS, PostgreSQL and the server for you.

  2. Install the apps and pair

    Run Codenvi.exe on each PC, enter the host name and password, then scan the PC's QR code with the Android app.

  3. Send a prompt

    Pick a project on your phone and type or speak. The PC runs Claude Code, commits to codenvi-dev and sends the encrypted answer back.

Self-host

One server, three lines of setup

The server name, host and port live in a GitHub secret, not in the repository. Keys are generated for you on the first deploy and never printed to the log.

  • Stops before changing anything if a name or port collides with another project
  • Switches back to the previous release if the health check fails
  • Gets and renews the Let's Encrypt certificate for you

FAQ

Questions people ask first

Is Codenvi free?

Yes. Codenvi is free and open source under the MIT License, for personal use. You run your own server, so there are no accounts and no subscription to Codenvi. Claude Code itself is governed by Anthropic's terms, and you sign in to it yourself on each PC.

Can my server read my prompts or code?

No. Prompts, replies, project names and commit messages are end-to-end encrypted with a key that only your PC and your phone hold. Your server only relays ciphertext, so even a compromised server cannot produce a valid encrypted prompt to run commands on your PCs.

Will Codenvi change my main branch?

No. Codenvi commits to a development branch (codenvi-dev by default). It never pushes, never merges to main and never rewrites history. You review the changes and merge them yourself, and you can roll back to any commit from the phone.

What do I need to run it?

A small Linux VPS with a domain name for the server, Windows 10 or 11 PCs with Git for Windows and Claude Code installed and signed in, and an Android 8 or newer phone. Codenvi is independent and is not affiliated with Anthropic.
